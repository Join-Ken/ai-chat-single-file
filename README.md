## 功能

| 功能 | 說明 |
|---|---|
| 多會話 | 左側列表管理，自動存 IndexedDB |
| 串流輸出 | 支援 DeepSeek 的 `reasoning_content` 思考過程 |
| 上下文摘要 | 訊息過多時自動壓縮成「前情提要」 |
| 本地 RAG | 純前端 TF-IDF 檢索早期對話，不調 embedding API |
| 記憶系統 | AI 可自動新增/修改/刪除記憶，也可手動編輯 |
| 檔案庫（僅聊天版） | 全局 G + 獨立 I，按關鍵詞命中注入；可讓 AI 請求全文 |
| 設定庫（僅 RPG 版） | 六類：角色 / 地點 / 勢力 / 物種 / 特殊物品 / 重大事件 |
| 狀態卡（僅 RPG 版） | `[STATE]` 記錄 hp / location / present / day 等，頂欄小藥丸顯示 |
| 骰子檢定（僅 RPG 版） | AI 輸出 `[ROLL]`，一鍵擲骰，結果交還 AI 續寫 |
| 封存 📦 | 壓成摘要後不再讀早期原文 |
| 修剪 ✂️ | 只保留最近 240 條，且只刪已進摘要的部分 |
| 聯網搜尋 | 接 Tavily API，可開關 |
| 檔案附加 | 把本地文字檔插入輸入框（5MB / 4 萬字符 / 總 8 萬字符上限） |
| 匯出/匯入 | JSON 全備份（含思考過程），無 Markdown 導出 |
| 思考模式 | 模型改 `deepseek-reasoner` 即可看到推理過程 |

## 快速開始

1. 下載 `index.html`
2. 用瀏覽器打開（雙擊即可，不需要伺服器）
3. 展開「API 設置」，填 Base URL、API Key、模型
4. 開始對話

預設對接 DeepSeek：

- Base URL: `https://api.deepseek.com/v1`
- 模型: `deepseek-chat`

## ⚠️ 相容性說明（重要）

本工具是**純前端**實作，請求直接從瀏覽器發出，因此**受 CORS 策略限制**。填 Key 前請先確認你用的服務是否允許瀏覽器直連。

**已實測可用**
- **DeepSeek**（`https://api.deepseek.com/v1`）：在作者本人的使用環境中可正常串流對話。注意：網路上關於 DeepSeek 是否開放 CORS 存在矛盾的說法，部分開發者報告仍會遇到跨域錯誤。**請以你自己的實測結果為準**。

**確認開放 CORS，理論上可用（未逐一驗證）**
- **OpenRouter**（`https://openrouter.ai/api/v1`）：多個獨立來源確認其 CORS 為開放狀態（`ACAO: *`），允許瀏覽器直連。

**可能需要額外設定，未驗證**
- **SiliconFlow**：有使用者回饋需要在帳號或 API 設定中**手動勾選「Enable CORS」**後，瀏覽器才能直連。預設狀態下可能失敗。
- **Kimi（`api.moonshot.cn` 中國區端點）**：有來源稱支援瀏覽器直連，也有來源稱官方 API 未開放 CORS。資訊矛盾，**不建議在未測試的情況下直接依賴**。

**普遍報告無法直接連線**
- **OpenAI 官方 API（`api.openai.com`）**：廣泛的開發者報告和技術文件均指出，OpenAI 官方端點會阻止瀏覽器直接請求，CORS 預檢通常會失敗。本工具**不建議**填寫 OpenAI 官方 Base URL。

**本地模型需自行放行**
- **Ollama**：預設**禁用跨域存取**，瀏覽器請求會被攔截。必須在啟動 Ollama 前設定環境變數放行來源，例如：
  - macOS / Linux：`OLLAMA_ORIGINS="*" ollama serve`
  - Windows（PowerShell）：`$env:OLLAMA_ORIGINS="*"; ollama serve`

若連線失敗，最常見的原因是 **CORS 攔截，而非 Key 填錯**。瀏覽器開發者工具（F12）的 Console 面板如果出現 `Blocked by CORS policy` 或 `No 'Access-Control-Allow-Origin' header`，就是跨域被拒，與 Key 無關。

## 技術亮點

（以下描述是 AI 寫給我看的，我本人無法驗證，僅供參考）

- **手寫 Markdown 解析器**：不依賴 marked/markdown-it，支援程式碼塊、表格、引用、列表
- **本地稀疏向量檢索**：TF-IDF + 餘弦相似度，中文按 2-gram 切分
- **空閒超時**：只要還在收資料就續命，60 秒完全沒動靜才中止，不會掐斷慢慢吐字的長回答
- **增量摘要 + 封存**：壓縮後標記 `sealed`，之後不再讀原文
- **安全修剪**：只允許刪除「已進摘要」的消息，未壓縮的一條都不刪；刪前可強制備份
- **檔案庫按需注入**：關鍵詞命中才送，單條超 800 字截斷，AI 可請求全文補一次
- **RPG 標籤三件套**：`[STATE]` / `[LORE_*]` / `[ROLL]`，回覆完成後自動剝離

## 已知限制

- 單檔案 2000+ 行，刻意設計，方便複製攜帶
- 手寫 Markdown 對複雜嵌套（列表裡的程式碼塊）支援有限
- RAG 是 TF-IDF 級別，不是語義向量，適合小規模對話
- 檔案庫注入按關鍵詞匹配，不做語義召回
- 沒有 Markdown 導出，只有 JSON
- 沒有多設備同步
