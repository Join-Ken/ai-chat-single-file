## 功能

| 功能 | 說明 |
|---|---|
| 多會話 | 左側列表管理，自動存 IndexedDB |
| 串流輸出 | 支援 DeepSeek 的 `reasoning_content` 思考過程 |
| 上下文摘要 | 訊息過多時自動壓縮成「前情提要」 |
| 本地 RAG | 純前端 TF-IDF 檢索早期對話，不調 embedding API |
| 記憶系統 | AI 可自動新增/修改/刪除記憶，也可手動編輯 |
| 聯網搜尋 | 接 Tavily API，可開關 |
| 檔案附加 | 把本地文字檔插入輸入框 |
| 匯出/匯入 | Markdown 單會話、JSON 全備份 |

## 快速開始

1. 下載 `index.html`
2. 用瀏覽器打開（雙擊即可，不需要伺服器）
3. 展開「API 設置」，填 Base URL、API Key、模型
4. 開始對話

預設對接 DeepSeek：

- Base URL: `https://api.deepseek.com/v1`
- 模型: `deepseek-chat`

## ⚠️ 相容性說明（重要）

本工具是**純前端**實作，請求直接從瀏覽器發出，因此**受 CORS 策略限制**。

- ✅ **已實測可用**：DeepSeek
- ❌ **無法直接連線**：OpenAI 官方 API（`api.openai.com` 不允許瀏覽器直連）
- ❓ **理論上可用、未逐一驗證**：其他開放 CORS 的 OpenAI 相容服務，例如 OpenRouter、SiliconFlow、Kimi（`api.moonshot.cn`）等
- ❓ **本地模型**：Ollama 等需自行設定 `OLLAMA_ORIGINS` 允許跨域，否則同樣會被瀏覽器攔截

填 API Key 前，請先確認你用的服務是否允許瀏覽器直連。若連不上，通常是 CORS 問題，不是 Key 填錯。

## 技術亮點

（以下描述是 AI 寫給我看的，我本人無法驗證，僅供參考）

- **手寫 Markdown 解析器**：不依賴 marked/markdown-it，支援程式碼塊、表格、引用、列表
- **本地稀疏向量檢索**：TF-IDF + 餘弦相似度，中文按 2-gram 切分
- **空閒超時**：只要還在收資料就續命，60 秒完全沒動靜才中止，不會掐斷慢慢吐字的長回答
- **增量摘要 + 封存**：壓縮後標記 `sealed`，之後不再讀原文

## 已知限制

- 單檔案 2000+ 行，刻意設計，方便複製攜帶
- 手寫 Markdown 對複雜嵌套（列表裡的程式碼塊）支援有限
- RAG 是 TF-IDF 級別，不是語義向量，適合小規模對話
